# Historical cash-flow charts

The integrated projection now carries sparse exceptions to the default losing
200-yen draw: winning payouts and BOX zero-cost skips. The browser reconstructs
every draw and verifies the totals, winning rounds, skip count, maximum drawdown,
longest losing streak and gross recovery against independently validated public
finance and risk summaries. Collinear points are removed without sampling;
no interpolation across wins or skips is invented. The charts show separate
counterfactual scenarios and do not grant purchase or model authority. Older
projections leave only the chart hidden. CI verifies actual generated Python
JSON in the JavaScript validators. No extra network request is needed.
The SVG is responsive with horizontal scrolling on narrow displays and text
summaries remain available. Actual browser rendering and Pages deployment
are separate verification steps.
